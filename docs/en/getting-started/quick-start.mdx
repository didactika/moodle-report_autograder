---
title: Quick start
summary: Open the report of an activity and read what Autograder decided.
order: 20
---

This task takes about five minutes. It needs an activity where Autograder is already enabled.

<Steps>
1. Open the activity and select **Autograder report** in its menu.
2. Read the table: each row is a student, with the status, the grading date, the grade and the teacher the grade is attributed to.
3. Use the search box and the filters above the table to narrow it down, for example to the students who are still pending.
</Steps>

<Screenshot src="asset:rp-activity.webp" alt="The Autograder report of an assignment, with one row per student" caption="The report of an activity, with one row per student." url="/report/autograder/index.php" />

The report appears in the menu of an activity only when Autograder is enabled in it, and you need the capability `report/autograder:view` in the activity. Editing teachers and managers have it by default.

> [!TIP]
> A pending student with **nobody** as their grader will fail to be graded when the date arrives, because no teacher can grade them at the moment. See [Graders by course](page:guides/graders-by-course) to fix it in advance.
