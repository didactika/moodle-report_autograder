**Requirements:** Moodle 5.3, PHP 8.3 or later and [Autograder](https://github.com/didactika/moodle-local_autograder). Moodle 4.0 to 5.2 have a line of their own with the same features.

| Moodle | Branch | Releases |
|---|---|---|
| 4.0 to 5.2 | `MOODLE_400_STABLE` | `X.Y.Z-m400` |
| 5.3 | `main` | `X.Y.Z-m503` |

<Tabs>
  <TabItem label="From a release">
    Download the latest release ZIP files of Autograder and of this report, go to **Site administration > Plugins > Install plugins**, upload each file and follow the prompts.
  </TabItem>
  <TabItem label="From Git">
```bash
cd /path/to/moodle
# Moodle 5.3
git clone https://github.com/didactika/moodle-local_autograder.git local/autograder
git clone https://github.com/didactika/moodle-report_autograder.git report/autograder
# Moodle 4.0 to 5.2
git clone -b MOODLE_400_STABLE https://github.com/didactika/moodle-local_autograder.git local/autograder
git clone -b MOODLE_400_STABLE https://github.com/didactika/moodle-report_autograder.git report/autograder
php admin/cli/upgrade.php
```
  </TabItem>
</Tabs>

After installing, managers and editing teachers can already open the report where Autograder is enabled. The next step is to [open it for the first time](page:getting-started/quick-start).
