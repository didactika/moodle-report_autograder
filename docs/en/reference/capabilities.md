---
title: Capabilities
summary: Every capability of the plugin, who has it by default and what it allows.
order: 40
---

| Capability | Context | Default roles | Allows the user to |
|---|---|---|---|
| `report/autograder:view` | Activity | Editing teacher, Manager | View the report of an activity |
| `report/autograder:viewcourse` | Course | Editing teacher, Manager | View the report of a whole course |
| `report/autograder:viewsite` | System | Manager | View the report of the site and the **Graders by course** page |
| `report/autograder:viewfailed` | Course | Manager | See which gradings failed, and why |
