Go to **Site administration > Reports > Autograder report > Grading report**. You need the capability `report/autograder:viewsite`, which managers have by default.

<Screenshot src="asset:rp-site.webp" alt="The Autograder report across the site, which asks for a course, an activity or another filter before it runs" caption="The report of the site asks for a filter before it runs." url="/report/autograder/index.php" />

The site report does not run unfiltered: it would ask the database about every enrolment of the site at once. Choose a course, an activity or another filter, and the table shows the students that match, with the course and the activity of each row.

Use it to check that nothing is stuck: filter by the status **Pending** and by a grading date in the past to find the grades that should already have been given, or by **Failed** to see which gradings failed and why.
