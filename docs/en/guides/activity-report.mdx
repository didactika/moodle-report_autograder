---
title: Activity report
summary: Follow the students of one activity.
order: 30
---

Open the activity and select **Autograder report** in its menu. You need the capability `report/autograder:view` in the activity.

<Screenshot src="asset:rp-activity.webp" alt="The Autograder report of an assignment, with one row per student" caption="One row per student of the activity." url="/report/autograder/index.php" />

The table lists every student of the activity with their groups, status, grading date, grade and grader. Above it:

- the **search box** looks for a student by name;
- the **group** filter narrows the list to one group, and only appears when the activity uses groups;
- the **status** filter shows only the students in the statuses you choose;
- the **grading date** filter limits the list to a period.

Select the heading of a sortable column to sort by it. Use **Clear every filter** to start again.

The report only appears in the menu of the activity when Autograder is enabled in it. For the meaning of each column, see [Statuses, dates and graders](page:concepts/statuses-and-dates).
