Each row of the report is one student in one activity. Its columns answer four questions.

## Status

| Status | Meaning |
|---|---|
| <Badge text="Pending" variant="note" /> | The student is scheduled to be graded on the date shown |
| <Badge text="Autograded" variant="success" /> | Autograder has graded the student |
| <Badge text="Graded by a teacher" variant="tip" /> | A teacher graded the student first, so Autograder did not |
| <Badge text="Failed" variant="danger" /> | Autograder tried to grade the student and could not. Only shown to the users who can see failures |
| <Badge text="Not autograded" variant="caution" /> | Autograder will not grade the student, for example because the grading was cancelled |
| <Badge text="Not submitted" variant="caution" /> | The student has not done the activity yet |

Above the table, the **Status** menu shows how many students are in each status. The numbers respect the other filters, so they always add up to the rows the report would show. The status **Failed** only appears to the users who can see failures.

## Date

The date is when the student will be graded, or when they were. The [details of the row](#the-details-of-a-row) say what the date is based on:

- the **due date** of the activity,
- an **override** of a user or of a group, or
- the **moment the student finished**, when the activity has no close date.

## Grade

For a pending student, the grade is the one the student will receive. It is shown in grey with the label **Provisional**, because it is not in the gradebook yet, and the teacher it will be attributed to is shown in grey too. A dash means that there is no grade yet.

## The details of a row

The button at the end of a row opens its details in a dialog: first what went wrong, when something did, and then the status, the grading date with what it is based on, the grade with the day it will be recorded, and the teacher with how that teacher is chosen. Its colour says how serious the most important thing is: blue when it only informs, amber when there is a problem and red when the grading failed.

## Grader

The teacher the grade is attributed to. For a pending student, it is the teacher it would be attributed to if the grade were given now. When nobody qualifies, the column shows the fallback grader of the site, if there is one, and otherwise says that there is nobody.

> [!WARNING]
> A pending student with **nobody** as their grader will fail to be graded when the date arrives. The report shows these students so that the problem can be fixed in advance. See [Graders by course](page:guides/graders-by-course).

The rules by which Autograder chooses the grader and the date are explained in the documentation of [Autograder](https://github.com/didactika/moodle-local_autograder).
