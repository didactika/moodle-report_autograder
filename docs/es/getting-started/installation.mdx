---
title: Instalación
summary: Requisitos y cómo instalar el informe desde una versión publicada o desde Git.
order: 10
---

**Requisitos:** Moodle 5.3, PHP 8.3 o posterior y [Autograder](https://github.com/didactika/moodle-local_autograder). Moodle 4.0 a 5.2 tienen una línea propia con las mismas funciones.

| Moodle | Rama | Versiones |
|---|---|---|
| 4.0 a 5.2 | `MOODLE_400_STABLE` | `X.Y.Z-m400` |
| 5.3 | `main` | `X.Y.Z-m503` |

<Tabs>
  <TabItem label="Desde una versión publicada">
    Descargue los ZIP de la última versión de Autograder y de este informe, vaya a **Administración del sitio > Extensiones > Instalar plugins**, suba cada archivo y siga las indicaciones.
  </TabItem>
  <TabItem label="Desde Git">
```bash
cd /path/to/moodle
# Moodle 5.3
git clone https://github.com/didactika/moodle-local_autograder.git local/autograder
git clone https://github.com/didactika/moodle-report_autograder.git report/autograder
# Moodle 4.0 a 5.2
git clone -b MOODLE_400_STABLE https://github.com/didactika/moodle-local_autograder.git local/autograder
git clone -b MOODLE_400_STABLE https://github.com/didactika/moodle-report_autograder.git report/autograder
php admin/cli/upgrade.php
```
  </TabItem>
</Tabs>

Tras la instalación, los gestores y los docentes con permiso de edición ya pueden abrir el informe donde Autograder está activado. El siguiente paso es [abrirlo por primera vez](page:getting-started/quick-start).
